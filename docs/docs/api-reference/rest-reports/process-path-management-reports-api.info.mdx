The READ-ONLY analytical surface of process-path-management's "Process Path Catalogue Growth & Change" data product (ADR 0007), served by the separate `cmd/pathmgmt-reports` binary over a read-only Postgres pool against the analytical database. It is NOT the OLTP `cmd/pathmgmt` API documented in apis/openapi.yaml: a different binary, port and database (ADR 0031).

The report is a projection over this service's own domain events, delivered as CloudEvents 1.0 on the `warehouse.process-path-management.analytics` topic and applied by `cmd/pathmgmt-projector`, the single writer. It is EVENTUALLY CONSISTENT: read GET /reports/catalogue-growth/freshness to see how long ago the most recently projected change happened.

Rows are keyed by UTC day bucket. Every counter is a count of events in that bucket. No route requires authentication (ADR 0005). Errors use RFC 7807 problem details (`application/problem+json`, ADR 0020).
