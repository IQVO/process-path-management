# Security Policy

## Supported Versions

Security fixes are applied to the latest commit on the `develop` branch and to supported releases on `main`.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through GitHub's [repository security advisory form](https://github.com/IQVO/process-path-management/security/advisories/new).

Include a clear description, affected component or version, reproduction steps or proof of concept, impact, and any suggested mitigation. We will acknowledge the report within 7 days and provide status updates as we investigate and remediate it.

Please avoid accessing, modifying, or deleting data that is not necessary to demonstrate the issue.
